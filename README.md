## English

Save editor for **Ocean's Heart** (Steam). It runs right in your browser, with nothing to install. Because it edits the save file instead of game memory, it keeps working after game updates (unlike Cheat Engine tables).

### Features
- **One-click cheats:** huge health, almost invincible, always revive, infinite magic, max money, full ammo, potions and food, one-hit kills.
- **Stats:** health, money, magic, defense and weapon power.
- **Items:** amount of every consumable and ingredient; add or remove equipment and keys.
- **World:** chests, doors, bosses and travel routes, grouped by place. You can "close" an opened chest to take its treasure again.
- **Quests:** progress of each quest and story flags.
- **Search all:** every entry in the save has a plain-language explanation, in English or Portuguese.

### How to use
1. Open `index.html` in your browser (or use the GitHub Pages link, if the repo has one).
2. **Close the game.** If you use Steam Cloud, turn it off for the game.
3. Press `Win` + `R`, paste `%APPDATA%\OceansHeart\oceans_heart_saves` and press `Enter`.
4. **Back up** `save1.dat` (or `save2.dat` / `save3.dat`).
5. Load the file in the editor, make your changes and click **Download file** (or **Copy edited save** and paste it in Notepad).
6. Put the edited file in the save folder, replacing the original.

### Privacy
Everything runs in your browser. Your save is never uploaded anywhere.

## Português

Editor de save para o jogo **Ocean's Heart** (Steam). Ele roda direto no navegador, sem instalar nada. Como mexe no arquivo de save em vez de na memória do jogo, continua funcionando depois das atualizações (diferente das tabelas do Cheat Engine).

### O que dá para fazer
- **Trapaças com um clique:** vida gigante, quase invencível, reviver sempre, magia infinita, dinheiro máximo, munição cheia, poções e comida, golpe fatal.
- **Status:** vida, dinheiro, magia, defesa e força de cada arma.
- **Itens:** quantidade de cada consumível e ingrediente; ganhar ou remover equipamentos e chaves.
- **Mundo:** baús, portas, chefes e viagens, agrupados por lugar. Dá para "fechar" um baú já aberto e pegar o tesouro de novo.
- **Missões:** andamento de cada missão e registros da história.
- **Buscar tudo:** cada informação do save tem uma explicação em português ou inglês.

### Como usar
1. Abra o `index.html` no navegador (ou use o link do GitHub Pages, se o repositório tiver).
2. **Feche o jogo.** Se usar Steam Cloud, desative-o para o jogo.
3. Aperte `Win` + `R`, cole `%APPDATA%\OceansHeart\oceans_heart_saves` e aperte `Enter`.
4. **Faça backup** do `save1.dat` (ou `save2.dat` / `save3.dat`).
5. Carregue o arquivo no editor, faça as mudanças e clique em **Baixar arquivo** (ou **Copiar save editado** e cole no Bloco de Notas).
6. Coloque o arquivo editado na pasta dos saves, no lugar do original.

### Privacidade
Tudo roda no seu navegador. O save nunca é enviado para lugar nenhum.
